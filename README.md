# Jogo da Velha

Projeto desenvolvido em Java como parte dos meus estudos de
Engenharia de Software.

## Sobre o projeto

Jogo da velha para dois jogadores executado pelo terminal.
O projeto utiliza uma matriz 3x3 para representar o tabuleiro,
permitindo realizar jogadas, validar posições, identificar
vitórias e detectar empate.

## Tecnologias

- Java
- Scanner
- Matrizes
- Estruturas condicionais
- Estruturas de repetição

## Funcionalidades

- Tabuleiro 3x3
- Alternância entre jogadores X e O
- Validação de jogadas
- Verificação de vitória por linhas, colunas e diagonais
- Detecção de empate
- Sistema simples de pontuação

## Como executar

1. Tenha o Java instalado.
2. Clone o repositório.
3. Compile o arquivo `Main.java`.
4. Execute o programa.

## Objetivo

Projeto criado para praticar lógica de programação,
matrizes, estruturas condicionais e de repetição em Java.
